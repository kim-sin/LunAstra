# LunAstra 4.0.0 — stateflow.1

## Changes

Adds typed PREPARE resources, exact-workspace checking, common path identity, one-call owner-bound request staging, batched crew-step/native wait routing, stale source-bound blocker reassessment, strict reusable-execution receipts, idempotent current-snapshot review/completion, and a persistent local research queue with verifier records and cooperative pause/checkpoint resume.

Version 4 uses separate state-v4; finish existing 3.x work with its matching build before installing. See [stateflow architecture and limits](V4_STATEFLOW.md).

## Honest validation boundary

The release evidence delivered beside the ZIP contains exact tests, counts, source/archive hashes and failed-iteration history. Local software tests are not live Windows/macOS Codex certification. Native worker events in tests are simulated; local queue subprocesses, test commands, filesystem work, SQLite and Git integrations are real. Speed, model quality, account usage and Astra parity are not measured by these tests.

This version is delivered locally. No repository, release, Drive library, subscription, model setting or user installation was modified automatically.
