# LunAstra 4.2.0 — Batchflow

A source-preserving update of 4.1: batch-based local research notification, indexed queue scheduling, shared byte-backed input fingerprints, fewer repeated baseline/map scans, short-context fixed-seven assignments, bounded report digests and explicit V1/V2 wire adapters.

The same root and six workers, independent reviewers, model gate, exact-byte final proof, same-ticket recovery, installation preservation and opt-in privacy-safe diagnostics remain. Current-turn applicability is strengthened. No user host is installed or authenticated by building this archive. Synthetic host tests are not live host certification.

See [implementation and limits](V4_2_PERFORMANCE.md). The delivery audit outside the package contains the actual completed test counts and hashes, not an assumed performance result.
